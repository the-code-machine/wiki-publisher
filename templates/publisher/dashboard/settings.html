About WikiPublisher

Information and references for this tool.

This tool is a prototype designed to simplify publishing JavaScript and CSS files from a public Git repository (like GitHub or GitLab) directly to Wikimedia as gadgets or user scripts.

It is based on the proposal from the Community Wishlist Survey 2022, which aimed to create a more streamlined workflow for developers contributing code to Wikimedia projects.

How it Works:

  1. Authenticate: Log in with your Wikimedia account (this is a dummy login for the prototype).
  2. Upload Files: Provide a URL to your public Git repository to fetch available .js and .css files.
  3. Map Files: Assign each source file to a destination wiki page (e.g., a user script or a gadget page).
  4. Publish: Add metadata like a title, description, and an edit summary, then publish everything with one click.
